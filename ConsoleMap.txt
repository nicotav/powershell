🌐 NETWORK FUNCTIONS (Core/Network/Network.ps1)
================================================================================

Test-NetworkConnectivity      Test connectivity to a target host or port
Get-DNSResolution             Resolve DNS for a hostname
Get-FirewallStatus            Check Windows Firewall status and profiles


🖥️  SYSTEM FUNCTIONS (Core/System/System.ps1)
================================================================================

Get-SystemInfo                 Retrieve comprehensive system information
Get-EventLogErrors             Get recent error events from Windows Event Logs
Get-SystemUptime               Check system uptime since last boot
Get-PerformanceSnapshot        Take a snapshot of system performance metrics


💾 STORAGE FUNCTIONS (Core/Storage/Storage.ps1)
================================================================================

Get-DiskSpaceReport            Generate disk space usage report for all drives
Find-LargeFiles                Find large files in specified path
Clear-TempFiles                Clear temporary files from common locations


⚙️  SERVICES FUNCTIONS (Core/Services/Services.ps1)
================================================================================

Get-ServiceStatus              Get detailed status information for a service
Get-FailedServices             List services that should run but are stopped
Get-ServiceDependencies        Get the dependency tree for a service
Restart-ServiceSafely          Restart a service with dependency handling


🔒 SECURITY FUNCTIONS (Core/Security/Security.ps1)
================================================================================

Get-UserPermissions            Get effective permissions for a user on a path
Get-LocalAdminMembers          List all members of local Administrators group
Get-SecurityAuditReport        Generate a basic security audit report
Test-PasswordPolicy            Check the current password policy settings
